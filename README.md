# 🍕 Pizzería "Bella Italia" - Sitio Web Oficial

¡Bienvenidos al repositorio de la página web oficial de **Pizzería Bella Italia**! Este es un sitio web responsivo y moderno diseñado para que los clientes puedan explorar nuestro menú, conocer nuestra historia y realizar pedidos en línea de forma rápida y sencilla.

## 🚀 Características del Proyecto
* **Menú Interactivo:** Filtros por categorías (Pizzas clásicas, Pizzas gourmet, Bebidas y Postres).
* **Carrito de Compras:** Sistema básico para agregar, editar y eliminar productos del pedido.
* **Diseño Responsivo:** Optimizado para visualizarse correctamente en teléfonos móviles, tablets y computadoras.
* **Formulario de Contacto:** Sección con validación de datos para reservas y consultas.

## 🛠️ Tecnologías Utilizadas
* **HTML5:** Estructura semántica del sitio web.
* **CSS3:** Estilos personalizados, diseño con Flexbox y Grid, y animaciones.
* **JavaScript (Vanilla):** Lógica del carrito de compras y dinamismo del menú.

## 📂 Estructura de Archivos
```text
├── index.html          # Página principal y menú
├── nosotros.html       # Historia y ubicación de la pizzería
├── contacto.html       # Formulario de reservas y contacto
├── css/
│   └── estilos.css     # Archivo de estilos generales
├── js/
│   └── app.js          # Lógica de JavaScript (carrito y menú)
└── img/                # Banco de imágenes de las pizzas y logo
```

## 💻 Cómo Ejecutar el Proyecto Localmente

Para ver y probar este proyecto en tu computadora, sigue estos sencillos pasos:

1. **Clona este repositorio** en tu máquina local usando la terminal:
   ```bash
   git clone https://github.com
   ```
2. **Navega a la carpeta** del proyecto:
   ```bash
   cd pizzeria-bella-italia
   ```
3. **Abre el archivo `index.html`** en cualquier navegador web (Chrome, Firefox, Edge, etc.) haciendo doble clic sobre él.

*Nota: También puedes usar la extensión **Live Server** en Visual Studio Code para abrirlo en un servidor local con recarga automática.*
