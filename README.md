# 🍕 La Esquina Pizzería

Sitio web informativo de una pizzería ficticia, desarrollado con **HTML5** y **CSS3**. Presenta un menú de pizzas, información sobre el negocio y horarios de servicio.

## Descripción

**La Esquina Pizzería** es una página web sencilla de una sola vista, creada como proyecto de práctica de desarrollo web. Sus secciones están conectadas mediante un menú de navegación para facilitar el acceso a la información.

## Características

- **Inicio:** bienvenida y enlace al menú.
- **Menú:** pizzas de queso, pepperoni y pollo a la BBQ, con precios por tamaño.
- **Nosotros:** descripción del concepto de la pizzería.
- **Contacto:** horarios de servicio y aviso sobre el cierre de pedidos.
- **Diseño adaptable:** estilos para computadoras, tabletas y celulares.
- **Navegación interna:** enlaces a las distintas secciones.

## Tecnologías

- **HTML5** para la estructura y el contenido.
- **CSS3** para colores, tipografía, distribución y diseño adaptable.

No utiliza JavaScript, bases de datos ni dependencias externas.

## Estructura del proyecto

```text
La-Esquina-Pizzeria/
├── index.html
├── estilos.css
└── README.md
```

## Cómo abrir la página

1. Descarga los archivos del proyecto.
2. Guarda **`index.html`** y **`estilos.css`** en la misma carpeta.
3. Abre **`index.html`** en tu navegador.

## Horarios mostrados

- **Lunes a jueves:** 11:00 a. m. – 10:00 p. m.
- **Viernes a domingo:** 11:00 a. m. – 11:30 p. m.
- **Pedidos:** se reciben hasta 30 minutos antes del cierre.

## Publicación con GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube **`index.html`**, **`estilos.css`** y **`README.md`** a la raíz del repositorio (sin una carpeta adicional que los contenga).
3. Entra a **Settings → Pages**.
4. En **Build and deployment**, elige **Deploy from a branch**.
5. Selecciona la rama correspondiente (por ejemplo, **main**) y **/(root)**, y guarda.
6. Utiliza el enlace de GitHub Pages que aparece después de la publicación.

**Importante:** GitHub Pages reconoce el archivo de entrada como **`index.html`**, en minúsculas. El archivo CSS debe llamarse exactamente **`estilos.css`**, tal como aparece en la etiqueta `<link>` del HTML.
