# La Esquina Pizzería

Sitio web estático hecho con HTML y CSS.

## Archivos
- `index.html` + `estilos.css`: página principal de la pizzería.
- `tarea-html5.html` + `tarea.css`: práctica de sintaxis, semántica y HTML5.
- `media/`: aquí van `pizza.mp4` y `ambiente.mp3` para la página de la tarea.

## Publicar en GitHub Pages
1. Sube todos estos archivos a la raíz de un repositorio.
2. En el repositorio: Settings → Pages.
3. En "Build and deployment", elige "Deploy from a branch", rama `main` y carpeta `/ (root)`.
4. Guarda y espera uno o dos minutos. La página quedará en `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
